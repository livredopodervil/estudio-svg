# RD Studio / GIL · Ponte audiovisual 0.2.1

Autoria principal: Rogério Duarte. Esta é uma integração por adaptadores, não a fusão dos motores. O Estúdio SVG V3.6 (`7e93c3b`) permanece autoridade de projetos audiovisuais, narração, microfone, voz TTS, áudio e montagem MP4. O GIL 0.2.0 permanece autoridade da composição procedural. A API local só retorna uma mídia validada; o editor associa a mídia à cena mediante ação explícita, sem gravar o projeto automaticamente. A projeção depende da fonte e do instante.

## Fluxo audiovisual
1. Na GIL, validar e aplicar, depois Baixar GIL. O arquivo `.gil` contém o documento editável, não um vídeo.
2. No Estúdio SVG, abrir cena → Clipe de vídeo na cena → Inserir GIL / SpatialSeed. Selecionar o `.gil`. Escolher duração (vazio = integral, até 60 s e 1800 quadros); confirmar se incluir efeitos. O servidor local usa o mesmo exportador Python/Node da GIL, sem outro interpolador.
3. A saída é um clipe MP4 opaco, posicionado pelo editor de clipes existente. Há um clipe por cena. O programa GIL fica dentro de `componente_gil` juntamente com hash, origem e duração. Pode ser baixado e reaberto na GIL. O ZIP de projeto existente preserva a fonte e os arquivos de mídia. Não há edição de cada objeto GIL individualmente pela UI de vídeo nesta revisão. A substituição/remoção de um clipe padrão desvincula a descrição GIL; as faixas de som explicitamente adicionadas permanecem e podem ser removidas no painel Áudio. Nenhuma gravação anterior é apagada.
4. Se efeitos forem escolhidos, o mesmo MP4 é referenciado como faixa independente em `audio.tracks` (volume inicial 0,5, regulável). O compositor de clipes descarta sua faixa de áudio por padrão; o mixer existente lê a faixa, evitando duplicar o som. Não substitui voice_file, voice_text, voice_enabled ou a trilha musical.
5. Gerar voz por cena (ou lote), ou gravar narração como antes. Rever duração. A voz sintetizada pelo navegador é opção de apresentação; o MP4 exige uma voz gravada ou o motor de síntese local configurado. Se `encaixe_voz=estender`, a cena pode ultrapassar o clipe. Ajustar trecho e chaveframes/re-renderizar, ou ativar Repetir. Não há alinhamento automático de palavras; a entrada procedimental dos objetos depende dos marcadores temporais da fonte. Efeitos em áudio não serão repetidos automaticamente ao repetir vídeo.
6. Não incluir informações privadas na fonte de componentes que serão publicados. O JSON carrega a fonte; ela não é um segredo nem uma credencial. Publicações requerem revisão de direitos e conteúdo.

## Página nativa
Na GIL, depois de aplicar o programa, indicar ID em Publicar composição como página e clicar Gerar componente HTML nativo. O RD Patch cria `projetos/<id>-nativo/` contendo `native.js`, `index.html`, `projeto.gil.txt`, `inserir.txt`, `component.json`. Instalar pela UI Pacotes IA e examinar diff. `inserir.txt` contém o módulo e o elemento a adicionar via editor HTML no ponto desejado. Múltiplas instâncias têm estado de apresentação independente; reprodução silenciosa automática, fundo transparente por padrão, `opaque` para incluir fundo, `once` para reprodução única. O laço de renderização cessa quando invisível, aba oculta ou movimento reduzido. A época continua durante invisibilidade; ao retornar, a fase é recalculada. CSS do host controla tamanho e posição. Não há iframe, API administrativa nem som. A apresentação nativa usa o renderer SVG experimental; não é WebGL.

## SpatialSeed (experimental)
`tools/launch.py --spatial <checkout confirmado>` fornece a localização explícita do SpatialSeed. A entrada `.spatialseed` é JSON schemaVersion 4. O adaptador chama `projectInstanceGraphScene` e `AppearanceRuntime` do checkout instalado, preserva hierarquia, transformações locais, dimensões de caixas, IDs de origem, cor e opacidade disponíveis. Cria câmera/luz novas e duração padrão 8 s; a fonte resultante é GIL, editável. Escopo suportado: grupos, caixas, incluindo ocorrências projetadas; 240 nós antes da expansão para GIL, pivôs zero, escalas positivas. Geometrias não suportadas são recusadas. Não importa fidelidade PBR, texturas, físicas, scripts, animações/epochs ou câmeras de origem. O arquivo original permanece no dispositivo. Pode converter na interface GIL → Importar SpatialSeed, validar, animar e exportar; ou inserir diretamente como clipe. Modelos nativos complexos ainda requerem saída intermediária pelo motor original (MP4 pelo fluxo de clipes).

## Testes, segurança, rollback
Limites do adaptador: fonte 250 kB, trechos .5–60 s, 1800 quadros, 64 MiB por MP4, subprocessos locais com limite de tempo e memória do conversor, origens HTTP específicas do loopback. Não recebe caminho, shell ou programa JavaScript arbitrário. O runtime publicado não consulta servidores administrativos.

Executar `node --test gil/tests/*.test.mjs` com RD_SPATIALSEED_ROOT, `PYTHONPATH="$PWD/rdstudio" python -m unittest discover -s rdstudio/tests -v`, e testes de integração. No Estúdio SVG, `RD_GIL_ROOT=<raiz-gil> python -m unittest discover -s tests -v`. O teste real usa tom sintetizado como voz de validação, não gravação física. Antes da publicação repetir no Android, preservar Git e conferir branch/revisão. `tools/publish_update.py` anterior é específico da versão 0.2.0; não publicar esta revisão com ele. A preparação de novo publicador deve partir do estado remoto confirmado.
